壹 / WHY —— 缘起与目标

为什么走进社区讲节气

二十四节气根植于中华农耕文明——古人以圭表测影、浑仪观天切分四季，用它指导农事、规划生活，堪称“中国人自己的气象历书”，并于 2016 年列入人类非物质文化遗产代表作名录。当城市生活逐步远离农田，节气的指导功能虽被现代气象服务替代，其文化根系却也面临代际断层：老人熟知、青年淡忘、孩童陌生。这正是我们出发的理由。

使

一份使命

响应“加强农耕文化传承保护”与文化强国、乡村振兴的时代要求，青年学子走出校园、深入社区，以美育为桥，让节气文化在现代城市生活中继续生根。

专

专业底气

团队来自生态与应用气象学院，应用气象、智慧农业两大专业在手——我们能讲民俗故事，更能讲清节气背后的天气气候原理与现代农业应用，科普不流于表面。

标

四重目标

  • 摸清社区不同年龄层居民的节气认知真实现状；
  • 找准传承中需要提升的环节与科普需求；
  • 践行“气象专业 + 非遗节气 + 社区美育”公益科普；
  • 沉淀一套可复制、可推广的实践模式。

叁 / JOURNEY 01 —— 观象

紫金山天文台：到节气的源头去

节气的科学源头在天文。太阳周年视运动划出二十四份“时间刻度”，而圭表测影、浑仪观星，正是古人手中的标尺。我们把第一站设在紫金山天文台：研学古代天文仪器与现代观测设备，理清节气“从何而来、如何算出”。

这一站决定了整场实践的“打开方式”——

① 宣讲怎么讲

不堆砌“冷知识”，按“观象授时 → 节气物候 → 农事民俗 → 现代气象与智慧农业的延续”设计知识脉络，让听众既知其俗、更懂其理。

② 调研问什么

围绕“知道哪些习俗 · 从哪儿获取 · 还想怎么学”设计分层访谈提纲，让调研带着科学框架出门，而不是漫无目的地聊天。

肆 / JOURNEY 02 —— 问俗

社区街头：与四代人聊节气

队员们分组走进社区休闲广场、步道与小区出入口，按年龄分层随机邀约居民开放式访谈，全程手写记录口述民俗、同步留存影像。受访者覆盖暑托班儿童、青少年、中青年上班族与退休长者——四代人的节气记忆，在街巷间完成接力。

长

长者 · 记忆完整者

熟知立秋晒秋、啃秋、时令食补等全套民俗，能背节气歌、谈农时；短板在于获取新知的渠道单一（口述 + 电视），社区里缺少固定交流平台。

中

中青年 · 碎片化

只记得少数标志性节气，民俗“听过名字、不懂寓意”，践行更少；知识多来自短视频碎片，反而对“节气 × 气象 / 智慧农业”的专业解读有较强求知欲。

青

青少年 · 课本派

会背节气歌，却对应不上物候与民俗，几乎没有生活实践经历；对纯理论宣讲接受度低，更欢迎趣味化、互动式科普。

童

儿童 · 待启蒙

对节气名词基本陌生，却对自然风物、天象故事、农耕小故事充满好奇——图文并茂的课件加手工互动，是打开认知的最佳钥匙。

知识渠道发现

  • 长辈口述、课本——大众最主要的知识来源
  • 短视频——中青年与青少年的主流渠道
  • 电视科普——仍服务着老年群体
  • 社区节气活动、场馆研学——覆盖面极低，线下实体科普阵地存在明显缺口

伍 / JOURNEY 03 —— 传薪

暑托班的节气课：把民俗“做”出来

宣讲的“最后一公里”在暑托班。团队面向 6–12 岁儿童开设二十四节气美育课堂，把街头听来的民俗与天文台学来的原理，转译成孩子们听得懂、玩得来的课——课堂观测显示：图文课件 + 手工互动最能抓住低龄儿童，天象与农事故事总能换来最踊跃的提问。

讲

民俗故事 · 导入

以应季民俗开场：立秋为什么要“晒秋”“啃秋”？先让孩子们“见过”，才谈得上“想懂”。

理

气象小知识 · 进阶

结合专业解释“立秋为何还热”“一场秋雨一场凉”背后的节气与天气逻辑，也把现代气象监测、大棚智慧温控等对比知识带进课堂。

手

手工美育 · 内化

树叶拼贴、节气手绘等低门槛创作，让孩子动手把节气“做”出来；作品带回家，课堂就延伸成了家庭话题。

陆 / INSIGHTS —— 调研发现

四个需要提升的切面

调研不回避问题：以下四组现状，正是节气文化在社区传承中最需要提升的切面；右侧对应给出提升路径——如实记录是为了找到出路，这些切面也将是后续实践持续用力的方向。

现状一 · 代际认知有落差

城市生活远离农事，年轻一代缺少节气民俗的生活场景与长辈口述机会，“老人熟知、青年淡忘、孩童陌生”的落差，需要更多带烟火气的场景去弥合。

→

提升方向 · 社区常态阵地

每季度固定节气公益课堂，组合“民俗故事 + 气象知识 + 手工创作”；开辟宣传栏，为老人建立口述民俗档案。

现状二 · 社区供给待丰实

节气专项活动仍偏少，形式多停留于传单与静态宣讲，对儿童和中青年的吸引力不足——供给的趣味性、频次都需要提升。

→

提升方向 · 高校实践体系

把“走访调研 + 少儿课堂 + 天文研学”固化为年度实践模式，配套专业科普课件与常态研学安排。

现状三 · 科普深度待拓展

常见讲解多讲民俗故事，少讲节气背后的气象原理与现代农业应用，大众“知其俗、未必知其理”——专业纵深的科普供给需要提升。

→

提升方向 · 双线融合传播

短视频轻量科普适配年轻一代；线下留存访谈记录、手工作品、研学影像，汇编成册免费发放。

现状四 · 长效机制待完善

高校专业资源下沉社区仍以一次性暑期实践为主，暑期过后服务易中断——校地协同的常态化机制需要持续提升。

→

提升方向 · 校地共建机制

与社区签订长期合作协议，分学期开展月度志愿科普，成果纳入第二课堂与实践评优体系。

柒 / PLAYBOOK —— 可复制模式

一套可以带走的三位一体模式

把本次实践提炼成“走访调研 + 少儿课堂 + 天文研学”三位一体模式：它同时回答三件事——民意怎么采集、文化如何到达下一代、宣讲的底气从哪来。任何一所高校、任何一座城市，都可以按这套逻辑组队出发。

访

走访调研 · 民意底座

分层访谈让科普“对症下药”，口述记录为社区留下民俗档案。没有成熟社区？乡村集市、公园、校园周边同样适用。

课

少儿课堂 · 传承主阵地

美育三段式把知识转译为体验，孩子带作品回家即成为“二次传播点”。暑托班之外，乡村少年宫、夏令营、中小学课后服务皆可承接。

研

天文研学 · 科学源头

场馆里的“为什么”让宣讲有原理底气，也补齐线下研学缺口。紫金山天文台之外，本地天文馆、气象台、科技馆、气象科普基地皆可平替。

四阶段操作流程

  1. 1

    筹备 · 定案

    选对时令主题（暑期实践宜选民俗浓度高的节气，如立秋）；完成三线对接：社区居委、暑托班 / 学校、本地科普场馆；备齐访谈提纲、课件初稿与影像设备；安全预案与肖像授权前置。

    产出：一页行动方案 + 物料清单
  2. 2

    调研 · 问俗

    分组分区，按“长者 / 中青年 / 青少年 / 儿童”分层覆盖；用“您年轻时这个时节吃什么、做什么”这类记忆钩子唤起口述；主问 + 记录双人搭档，全程留影。

    产出：口述记录 · 影像 · 问卷
  3. 3

    授课 · 传薪

    按“民俗故事 → 气象小知识 → 手工美育”三段式开讲，控制单课时长与互动节奏；讲师 + 助教配合，助教专职记录课堂反应与作品。

    产出：课堂照片 · 儿童作品 · 观测笔记
  4. 4

    沉淀 · 交付

    当日事当日归档，统一命名“日期_地点_内容”；按活动要求备齐：高清照片不少于 10 张、视频 1–2 段（每段 3–5 分钟）、项目质量报告（不少于 5000 字）与 PPT；以“学校 + 团队名称 + 二十四节气美育实践成果”命名报送。

    产出：全套成果包（报告 · PPT · 影像 · 科普材料）

现成模板（复制即用）

访谈提纲模板

开场（记忆钩子）：您好，我们是南京信息工程大学的大学生，在做二十四节气民俗的社会调查。您年轻时，到了【X 节气】家里都吃什么、做什么？

一、认知与记忆：1. 您能说出几个节气？能背节气歌吗？2. 咱们本地过【X 节气】有哪些讲究（饮食 / 习俗 / 禁忌）？3. 这些习俗您是从哪儿听来的（长辈口述 / 电视 / 手机 / 课本）？

二、渠道与行为：4. 平时从哪些渠道接触节气知识？5. 家里现在还按节气安排生活吗（吃什么 / 做什么）？

三、需求与期望：6. 如果社区办节气活动，您希望是什么形式（讲座 / 手工 / 养生 / 亲子）？7. 您愿意听大学生讲节气里的气象和农业科学吗？

记录要求：标注受访者年龄段；原话尽量完整记录；拍合影前先征得同意。

课堂教案框架模板（40 分钟）

导入 5'：应季民俗提问（“立秋了，你家吃什么？”），亮出今天的主角节气。

民俗故事 10'：讲本地习俗由来与寓意，穿插“晒秋 / 啃秋 / 数九”等生活画面。

气象小知识 10'：该节气的天气气候特点 + 一个“节气 × 现代农业”对照案例 + 1–2 个课堂提问。

手工美育 12'：树叶拼贴 / 节气手绘等低门槛创作，助教巡堂记录。

收尾 3'：请 2–3 名孩子展示并复述“今天学到了什么”，发放科普小卡。
