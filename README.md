# 扎根社区探节气文脉 · 气象赋能传千年民俗

南京信息工程大学生态与应用气象学院暑期实践团队 —— 二十四节气美育文化社区实践成果展（静态单页网站）。

## 内容结构

- 观象：紫金山天文台研学溯源
- 问俗：社区街头四代人访谈
- 传薪：暑托班节气美育课堂（含视频）
- 调研发现：四个需要提升的切面与提升方向
- 可复制模式：走访调研 + 少儿课堂 + 天文研学"三位一体"模式包
- 给后来者：一页纸行动清单、访谈提纲 / 教案 / 归档模板

## 本地预览

直接双击 `index.html` 即可（纯静态，无需服务器）。

## 更新方法

1. 照片放入 `img/`、视频放入 `video/`；
2. 在 `js/main.js` 的 `GALLERIES` 中登记新文件名（或替换同名文件）；
3. 文字内容直接编辑 `index.html`；
4. 提交推送后，GitHub Pages 自动重新发布（约 1–2 分钟）。

## GitHub Pages 发布

仓库 Settings → Pages → Source 选 `Deploy from a branch` → `main / (root)` → Save。
访问地址：`https://<用户名>.github.io/jieqi-site/`
